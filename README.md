# 起身 · StandUp

原生 SwiftUI 菜单栏工具，默认累计 45 分钟有效工作后提醒起身，确认后计时 15 分钟站立 / 活动。所有设置与统计保存在本机，无网络请求、账户、第三方依赖或键盘内容记录。

## 运行

需要 macOS 14+、Xcode / Swift 6 工具链。在本项目目录执行：

```sh
./script/build_and_run.sh
```

产物：`dist/StandUp.app`，也可以直接在 Finder 双击。菜单栏显示椅子 / 站立图标和剩余时间，不显示 Dock 图标。点击菜单栏打开面板。项目自带 `.codex/environments/environment.toml` 的 Run 动作。

首次在「设置 → 开启通知权限」中允许提醒；通知关闭或被专注模式抑制时，菜单栏仍会显示「起身」。登录启动为主动选择，开关直接调用系统登录项 API；应用位置应保持稳定。

## 已实现的规则

- 启动、恢复后等待新的输入；旧的键鼠活动不会自动开始一轮。
- 闲置默认 90 秒暂停。短暂离开或锁屏保留工作进度；连续离开达到休息时长，返回时清零进入新一轮。
- 45 分钟到点进入「该起身了」，不会擅自记录站立或完成休息。
- 点击「我站起来了」后计时；站着打字不会取消休息。到点提醒一次，继续站立也可以。
- 点击「我坐下了」回到等待工作；提前坐下记录为提前结束，不计为完成。
- 每轮可顺延一次，默认 5 分钟；跳过本次开始新一轮。
- 手动暂停保留阶段与进度，恢复不会计入暂停时间。
- 计时使用单调时钟，不受手动调整系统日期影响；系统不可用和长时间调度间隔不累计工作。
- 设置、进度、每日统计本地保存；每 15 秒与状态变化时保存，正常退出保存。异常退出最多损失约 15 秒。
- 重启不会把 App 关闭期间算成工作或完成休息；从已保存进度继续。日期变化归档当天统计，保留当前周期。
- 显示最近 7 个有记录日期的统计；本地保存全部历史，不限制 7 天。

## 开发与检查

```sh
./script/build_and_run.sh --dev       # 45 秒 / 15 秒；闲置 5 秒；顺延 5 秒
./script/build_and_run.sh --verify    # 正式节奏，打包并验证进程
./script/build_and_run.sh --build     # 只构建 .app
./script/build_and_run.sh --preview   # 原生视图预览，写入 work/previews 后退出
swift test                          # 状态机回归测试
```

测试模式的设置与统计独立保存，节奏固定，不修改正式配置。还支持 `--debug`（LLDB）、`--logs` / `--telemetry`（当前进程系统日志）。脚本从任何工作目录启动都能正确构建。

## 安装到应用程序

```sh
./script/build_and_run.sh --install
```

这个命令会构建 Release 版本、把 `Stand Up.app` 安装到 `/Applications`、刷新系统注册并启动应用。安装后可从 Launchpad、Spotlight 或 Finder 启动，不需要再打开终端。当前版本使用本机 ad hoc 签名，适合本机使用；跨设备分发需要 Developer ID 签名与公证。

应用图标源文件：`Resources/IconPreview/stand-up-icon.svg`，最终图标：`Resources/StandUp.icns`。

## 习惯系统

菜单栏中的 `Progress` 会打开完整的本地进度窗口，包含每日目标、连续天数、最佳连续天数、自然月日历和成就。默认每日目标为 6 次，旧记录没有目标字段时按 6 次解释。

设置中的“渐进训练”默认关闭。开启后从 Level 3（45 分钟工作 / 15 分钟站立）开始，每完成 5 个达标日自动升一级，最高 Level 11；升级只影响下一轮节奏，不会改写当前正在进行的计时。每日目标可以调整为 1 到 20 次，历史日期会保留当时的目标。

## 提醒方式

到点时应用提供三层提醒：系统通知、系统声音和屏幕顶部的悬浮提醒卡片。悬浮卡片直接提供 `I'm standing`、`Snooze` 和 `Skip`，不强制锁屏，也不会接管键盘。设置中可以分别关闭声音和悬浮卡片，并点击“预览提醒”检查当前效果。

## 场景增强

第三阶段已包含：

- 会议模式：手动暂停有效工作计时。
- 智能会议延后：前台应用为 Zoom、Teams、Webex、Slack、FaceTime 或 Google Meet 时暂停有效工作计时。
- 快捷键：⌥⌘P 暂停 / 恢复，⌥⌘S 立即开始站立。
- 全屏休息提示：可选，开启后到点在所有屏幕显示动作建议和休息倒计时。
- 统计增强：Progress 页面增加累计工作时间、完成休息次数和目标完成率。

视频播放、长时间阅读和演示模式目前保留为后续的可解释启发式规则，避免把深度工作误判为离开。

悬浮提醒卡片会淡入上移、图标轻微呼吸，并在出现几秒后做一次短促横向提示；开启系统“减少动态效果”后自动关闭这些动画。

## 设置与语言

设置窗口采用原生 macOS 分栏布局，分为通用、坐站节奏、提醒、场景增强、快捷键和关于六个页面。语言可以选择“跟随系统”、中文或 English；切换会立即应用到菜单栏、设置、进度、通知、悬浮提醒和全屏休息提示，不需要重启，也不会重置当前计时。工作时长、站立时长、提醒方式等其他修改保留草稿状态，点击“保存设置”后生效。
