# Privacy

Stand Up is designed to run locally on your Mac.

The app stores timer settings, current timer state, daily summaries, streaks, achievements, and habit progress in local preferences. It does not require an account and does not send activity data to a server.

For activity detection, the app asks macOS for the elapsed time since the most recent input event. It does not record key contents, mouse coordinates, window titles, screenshots, or documents.

Notifications, sounds, sleep/wake handling, and the optional floating reminder are generated locally by macOS frameworks.

This privacy notice describes the current open-source build. A future App Store build may have additional Apple-managed services or disclosures if optional capabilities are added.
